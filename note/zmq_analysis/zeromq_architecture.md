### 4.2 ipc_listener_t 核心实现

位置: `src/ipc_listener.cpp`

```cpp
class ipc_listener_t : public stream_listener_base_t
{
    // 关键成员
    std::string filename;              // socket文件路径
    int sock;                          // 监听socket fd

    // 关键流程:
    // 1. resolve_endpoint() - 解析IPC地址
    // 2. create_ipc_file() - 创建临时目录和socket文件
    // 3. bind() - 绑定Unix Domain Socket
    // 4. listen() - 开始监听
    // 5. accept() - 接受连接，创建新session
};
```

### 4.3 ipc_connecter_t 核心实现

位置: `src/ipc_connecter.cpp`

```cpp
class ipc_connecter_t : public stream_engine_base_t
{
    // 关键成员
    std::string endpoint;              // IPC端点路径
    int sock;                          // 连接socket fd

    // 关键流程:
    // 1. resolve_endpoint() - 解析IPC地址
    // 2. open_socket() - 创建Unix Domain Socket
    // 3. connect() - 连接服务器
    // 4. get_peer_credentials() - 获取对端凭证
    // 5. send_bind() - 发送绑定命令
};
```

### 4.4 Unix Domain Socket 特性

| 特性 | 说明 |
|------|------|
| 文件系统路径 | `/tmp/zmq-xxxxx-xxxxx.ipc` |
| 自动创建目录 | ZeroMQ创建临时目录 |
| 权限控制 | 通过ZAP协议验证 |
| 凭证传递 | SO_PEERCRED 获取PID/UID/GID |
| 原子性 | AF_UNIX保证原子性 |
| 同一主机 | 仅限本机进程间通信 |

### 4.5 ZMTP 协议帧格式

```

  │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  │ flag│  length (8 octets) │     payload (variable)        │ more │
  └─┴─┴─┴─┴─┴─┴─┴─┘└─┴─┴─┴─┴─┴─┴─┴─┘└─┴─┴─┴─┴─┴─┴─┴─┘└─┴─┴─┴─┴─┘

  flag:
    0x00 = regular message
    0x01 = more message parts follow
    0x02 = command (not message)
    0x04 = long message (length > 255)

  length: 消息体长度 (8字节可变长编码)

  payload: 实际数据 (可能为命令或消息)
```

                    ┌─────────────────────────────────────┐

## 7. 与 jlrpc 对比

| 方面 | ZeroMQ | jlrpc |
|------|--------|-------|
| 传输层 | 抽象良好的传输层 | 直接使用ASIO |
| 协议 | ZMTP (自定义) | 自定义PbCoder |
| 会话管理 | session_base_t | PbSession |
| 线程模型 | IO线程池 | ASIO io_context |
| IPC | inproc/ipc/tcp/pgm | 仅TCP |
| 无锁队列 | ypipe | 无 |

### jlrpc 可借鉴的设计:

1. **传输层抽象** - 可类似ZeroMQ定义 `i_transport` 接口
2. **邮箱机制** - `mailbox_t` 设计可用于session与socket通信
3. **无锁队列** - `ypipe` 可用于线程池任务队列
4. **命令模式** - 对象间通过 `command_t` 通信
